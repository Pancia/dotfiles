Reply format options

One invented reply in eight formats. Each panel is a real capture from Claude Code 2.1.319, so bold, color and wrapping are what your terminal draws. The dark background is an approximation.

What I found

  • The four sections are mostly gone now. A rule change on Nov 8 at 12:34 removed them and banned section headings.
  • On Nov 7, before the change, 52 of 92 longer replies used the sections and 39 had no structure.
  • On Nov 9, 254 of 264 had only a Needs you part, 3 used the sections and 7 had no structure. The facts above Needs you have no fixed format.
  • The terminal has few tools. Bold shows as bold. A heading shows as bold plus blank lines. Inline code is the only color, a light blue.
  • Three dashes stay as three dashes, so a horizontal rule does not draw a line.
  • The commit command still asks for the four sections, so its replies follow a format the global rules no longer have.

I recommend H. The left edge becomes a column you can read down, and the questions stand apart. In this sample it uses 6 fewer words than today's format but 5 more lines. G is the same format without color, if the blue labels look too much like code.

Labels appear only when they apply. A small job stays one or two lines. The labels are a suggested set, and you can change the words.

Part 2: how to make the format hold

A format only helps if replies use it. These four can be combined. None of them is built yet.

OptionWhat it doesWhen a miss is correctedMain cost
Rule text onlyAdd the format to the global reply rules.NeverReplies can drift, as the Nov 7 numbers show.
Reminder on each promptExtend the Altera reminder to all sessions. It also checks the last reply for the labels.Next replyOne extra line of context per prompt. The current reply stays wrong.
Check at end of turnA hook rejects a reply that has no labels, and Claude writes it again.Same turnYou see both copies. It must skip replies that only answer a question.
Side paneA mod copies the labeled lines into a pane beside the chat.Does not correctMost work. Needs fixed labels. I did not test an automatic pane.

I recommend the rule text plus the reminder. The reminder already exists and calls no model. The end-of-turn check is the next step if misses continue.

Counts cover interactive replies of 40 words or more, from the 400 most recently changed session files. The quality notes are my judgment.
