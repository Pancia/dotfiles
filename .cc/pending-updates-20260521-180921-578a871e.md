```markdown
### Session Recovery (Open-Session Tracking)

Every `claude` invocation through the wrapper registers itself in `$XDG_STATE_HOME/claude-sessions/open/`. On clean exit (when you `ccsave` or exit normally), the entry is deleted. If the machine loses power or the process crashes, the entry persists as a breadcrumb.

**State directories:**
- `~/.local/state/claude-sessions/open/` — Active and unrecovered sessions (one JSON file per PID+epoch)
- `~/.local/state/claude-sessions/archive/` — Previously-resumed unrecovered sessions (moved from open by `ccs old`)

**Classifications in `ccs list`:**
- **● Saved** — explicitly ccsaved sessions (in `~/Cloud/cc-sessions/*/sessions.json`)
- **● Running** — live process (open entry with matching PID), switch to it via `ccs resume`
- **⚠ Unrecovered** — crashed or power-loss session (dead PID), resume with `ccs resume`
- **✓ Archived** — previously-resumed unrecovered sessions, view with `ccs old`

**Workflow:** Use `ccs list`/`ccs resume` as your normal entry point. If your machine loses power, run `ccs list` on next boot — unrecovered sessions appear with ⚠ marker. Resume them to switch back to their directory and project state.
```
